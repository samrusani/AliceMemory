# Alice v0.10.1 Release Notes

> **Correction (2026-09-27):** the audits and review passes named in these notes were internal adversarial review, not an independent or external audit.

`v0.10.1` is a security, reliability, and quality release. It supersedes the
tagged-but-unpublished `v0.10.0` candidate: `v0.10.0` remediated the third
external audit's findings, but its protected semantic release gate failed on a
query-interpretation defect and it was never published. `v0.10.1` carries all of
that remediation forward and closes the gate failure.

## Fix that closes the v0.10.0 gate

- **Business-money queries stay in vector retrieval.** The ambiguous word
  `money` in a query no longer infers a hard `personal`-domain filter, which had
  excluded the professional corpus before vector ranking (so a query like
  "advertising money" returned no vector candidates). Ambiguous business/money
  queries now remain unscoped; explicit caller-supplied domains stay strict.
- **Honest release aggregation.** The semantic release gate applies each suite's
  declared aggregate targets rather than requiring perfect per-case recall.
  Diagnostic case misses remain visible in the report, while skips, missing
  vector participation (`pass_fts_only`), malformed evidence, and failed target
  checks all still fail closed. Attestation validation now accepts truthful
  off-window ranks (6–10) instead of assuming any target outside the displayed
  top five has reciprocal rank zero.

## Carried forward from v0.10.0

All third-audit remediation: one signed-vector write contract across the eval
seeder and both backfill paths; scope/status/domain/sensitivity-aware atomic
capture dedupe (migration `0085`); people/time predicates pushed into the store
with bulk entity-edge resolution; fail-closed lifecycle cycle detection with 3+
duplicate-pointer repair (migration `0086`; `0084` unchanged); authoritative
roll-up totals; iterative HNSW scan on filtered vector search; and the P2 backlog
(pgvector 0.8+ enforcement, import/backup hardening, web decomposition with
browser/a11y/coverage gates, zero-error web typecheck, clean first-party mypy,
portable packaged-README links, structured exact-SHA release-control attestation).

## Upgrade

`alembic upgrade head` applies migrations `0085` and `0086` (idempotent; safe
downgrades). After upgrade, run `alicebot vnext memories backfill-embeddings` to
re-embed existing vectors under the endpoint-aware v2 signature; those vectors
are retrievable. No other operator action is required.

## Verifying this release

Alice publishes to PyPI through GitHub Trusted Publishing. Once published, the
wheel and source distribution carry PyPI's integrity attestations, which bind
each file to this repository, the release tag, the publishing workflow, the
exact commit, the release event, and the protected `pypi` environment —
verifiable on the project's PyPI page. Their exact SHA-256 digests will be
recorded in `docs/release/v0.10.1-checksums.txt` in this repository as part of
the post-publication commit.
