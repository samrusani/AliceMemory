# Alice v0.24.0 Release Notes
<!-- alice-release-state: {"schema_version":"alice_release_document_state_v1","version":"0.24.0","publication_status":"pending","checksums_status":"pending"} -->

**Agents sharing a vault can now record structured lessons and find published lessons relevant to their work. A lesson written by an agent without publishing standing waits for approval before it is shared. This release also tightens agent key checks, repairs two shipped smokes and updates the installer. See "What to do after upgrading".**

## What to do after upgrading

1. Upgrade the copy your hosts run with `uv tool upgrade alice-memory` or `pip install -U alice-memory`, check `alice-memory --version`, and restart the hosts.
2. For a keyed caller, omit identity fields or narrow the profile and scope to the key. A claim beyond the key is refused.
3. The Claude Code marketplace on `main` pins v0.23.1 until the post-publication change moves it. A marketplace install therefore runs v0.23.1 until then.

This release needs no database migration: the PostgreSQL migration files and the stored schema of the SQLite vault are those of v0.23.1.

## Lessons

`alice_memory_commit` and `POST /v0/vnext/memories/commit` accept an optional structured `lesson` with `applies_when`, `what_happened`, `do_instead` and optional repository-relative `paths`. v0.23.1 did not have this block. An owner or an `admin_agent` can publish a lesson at once; other writers need approval through `alice_memory_correct`. The instruction-shaped hard floor still applies, including to the owner. `alice_lessons` returns matching published lessons the caller may read, is on the default MCP surface, and can include the writer and publishing act. The session brief can name the number of readable published lessons. See [shared lessons](../alpha/shared-lessons.md) for the shape, approval and lifecycle rules.

## Keys and identity

Keyed calls read flat and nested identity claims together and keep the stricter profile and scope. v0.23.1 ignored flat claims beside a nested identity. MCP now returns `identity_claim_refused` for a keyed caller's overclaim or blank scope item; v0.23.1 returned `not_permitted`.

## Reads

SQLite ranked reads for a key with read limits use statistics from readable ordinary memories or source chunks, while derived memories remain eligible. v0.23.1 used table-wide counts. Owner, unbound admin and keyless declared identity reads keep their existing ordering.

## Checks and install

The agent integration smoke gives its seed the requested project, and capture-to-brief uses the current report date. On a fresh user, the first failed from v0.9.2 through v0.23.1 because its seed lacked a project; the second failed from v0.10.3 through v0.23.1 on days other than 2026-05-11 because its input requested that fixed date. These were faults in the checks' own inputs, so `alicebot vnext alpha check` could report failure on a healthy installation.

Codex install refuses an `mcp_tool` input containing a whole number from 2^63 through 2^64-1, including nested values; v0.23.1 accepted it. Codex 0.166.0, 0.167.0 and 0.169.0 skipped the tested hooks files, while 0.164.0 loaded them; install follows the version it is tested against, 0.169.0.

The showcase walkthrough runs as a plain command from a checkout, and the scripted demo records the June price as the step replaced by the November correction. The README is rewritten around long-term memory with permissions for a company's teams of agents. The chunk-vector build avoids the extra matrix-sized peak seen at the first append on the measured Linux runner.

## Records and tooling

The [limitations page](../alpha/known-limitations.md) adds thirteen bullets about current limits. The baseline scanner is pinned to 1.9.4. Mutation replay rejects archives ignored by an enclosing Git repository, defaults `BENCH_TEST_SOURCE` to the source repository when unset, and removes stale mutant logs before a baseline. The unit suite runs in eleven shards, and the publish and rehearsal limits are 300 minutes.

## Behaviour changes an integrator will notice

The default MCP surface adds `alice_lessons`. A keyed identity overclaim returns `identity_claim_refused` rather than `not_permitted`; omit the identity fields or narrow the claim to the key and retry. A lesson write that awaits approval answers `review_required` with reason `lesson_requires_approval` for a writer without publishing standing.

## Security

This release was checked with automated security scanning and internal adversarial review, findings triaged and fixed. No one outside the project has audited the code.

A valid key's refused overclaim records an `agent.key_escalation_rejected` event after rollback, with repeated equivalent claims within 60 seconds sharing one event; v0.23.1 rolled the event back or recorded repeated events from a brief. Retirement of a pending write requires standing to decide it, while v0.23.1 allowed project and trusted keys to retire another agent's pending write. Retirement or restoration of a lesson requires publishing standing. An agent source capture above its sensitivity ceiling is refused without storing the source; v0.23.1 stored it. Key revocation searches all keys by id or prefix, including revoked keys for prefix ambiguity; v0.23.1 searched only the 200 newest. Context-pack events keep a cleaned query of at most 128 characters and withhold credential-shaped text; v0.23.1 stored the full query. No security advisory is planned for this release.

## What this release does not claim

Lessons written before the first key keep their standing after keys are issued. Every key of a project can read its waiting and rejected lessons through the full review and explain tools, and explain returns the decision reason. A lesson's reader sees the writer and publishing agent ids, so choose neutral ids. `alice_lessons` reads a projection of every lesson the caller may read, so its cost grows with that number. See the [known limitations](../alpha/known-limitations.md) for these and the other limits of the alpha.

```bash
pip install alice-memory==0.24.0 && alice-memory install
```
